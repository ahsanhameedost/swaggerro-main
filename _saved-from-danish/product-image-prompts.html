Product image generation prompts

Detailed, copy-ready prompts for generating the storefront's product photography with an AI image model. Each prompt is self-contained — one click copies the full prompt, including the shared studio style so the whole catalog comes out as a cohesive set.

How to use: generate each at 1024×1024 (square), then export as JPG and save into public/products/<slug>.jpg using the filename shown on each card. Keep the same background and lighting across every product so the shop grid stays consistent. Products are intentionally blank / unbranded — logos get added later in the app's mockup tool.
